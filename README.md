# Sports Stats

Interactive sports infographics built with [D3.js](https://d3js.org/) and open data.

**Live site:** https://angelmza1990.github.io/sports-stats-mvp/

The site is plain HTML, CSS and JavaScript with no build step, served by GitHub Pages. Every page shares the navigation, the sport colors and the type (Barlow Condensed for headlines, self-hosted under the SIL Open Font License) from [`assets/`](assets/).

### Automatic updates

A [GitHub Actions workflow](.github/workflows/update-data.yml) rebuilds every dataset **twice a year**, on July 1 (after the NBA Finals) and December 31 (after the ATP Finals), commits any changes and republishes the site. It can also be run by hand from the Actions tab. If a dataset fails validation, the previous version is kept and the run is marked as failed.

### Robustness

- **The pages don't depend on the sources.** Every page reads a JSON file kept in this repository, so the site works even if Wikipedia or the tennis data mirror goes down.
- **No third-party code or flags at view time.** D3 is served from [`assets/vendor/`](assets/vendor/) and every flag from [`assets/flags/`](assets/flags/) ([`scripts/fetch_flags.py`](scripts/fetch_flags.py) fetches any new one after each update). Only the football crests still load from ESPN's CDN, and a club shows its initials if one fails.
- **Snapshots of every source.** [`data/raw/`](data/raw/) keeps the last downloaded copy of every Wikipedia page and match file. If a download fails, or a page is deleted, the builds use the saved copy instead, so the data can always be rebuilt.
- **Checks before anything is published.** Each build validates its data against known totals and keeps the previous version if a check fails, and a [page check](.github/workflows/check-pages.yml) opens every page in headless Chrome on each push and fails on script errors, missing files, pages that render nothing or sideways scrolling on a phone.

### Rebuilding the data

```bash
python3 scripts/build_big_three.py --refresh  # tennis: re-downloads the raw match files
python3 scripts/build_grand_slams.py --refresh # tennis: Open Era Grand Slams, men and women
python3 scripts/build_masters.py --refresh    # tennis: ATP Masters 1000 and WTA 1000
python3 scripts/build_nba_rings.py --refresh  # NBA: re-downloads the Wikipedia table
python3 scripts/build_super_bowl.py --refresh # NFL: Super Bowls, NFL champions since 1920, MVPs and coaches
python3 scripts/build_stanley_cup.py --refresh  # NHL: Stanley Cup Finals since 1915, Conn Smythe and coaches
python3 scripts/build_football.py --refresh   # football: club competitions and Argentine league
python3 scripts/build_leagues.py --refresh    # football: Serie A, La Liga, England, Ligue 1, Germany, Brasileirão
python3 scripts/build_football_people.py --refresh  # football: coaches and players (after the two above)
python3 scripts/build_team_coaches.py         # winning coaches of the team sports (only new editions are looked up)
python3 scripts/build_world_cup.py --refresh  # football: FIFA World Cup
python3 scripts/build_rivalries.py --refresh  # football: the four rivalries, match by match
python3 scripts/build_f1.py --refresh         # motorsport: Formula 1
python3 scripts/build_atp_records.py --refresh  # tennis: ATP and WTA career records (after build_masters.py)
python3 scripts/build_tennis_ages.py --refresh  # tennis: age records (after build_grand_slams.py)
python3 scripts/build_number_ones.py --refresh  # tennis: every spell at world No. 1
python3 scripts/build_tour_finals.py --refresh  # tennis: ATP and WTA Finals (after build_big_three.py downloads the match files)
python3 scripts/build_tournaments.py --refresh  # rugby, basketball, volleyball, hockey, handball
python3 scripts/build_swimming.py --refresh     # swimming: Olympic medalists
python3 scripts/build_olympics.py --refresh     # Olympic Games (Summer and Winter)
python3 scripts/build_olympic_sports.py --refresh  # Olympic tennis and boxing (after build_olympics.py)
python3 scripts/build_chess.py --refresh       # chess: also re-downloads the PGN Mentor player files
python3 scripts/fetch_flags.py                  # download any flag a dataset now needs
```

Leave out `--refresh` to rebuild from the saved copies in `data/raw/`, with no network access.

To check every page locally: `npm install --no-save puppeteer-core@23.11.1 && CHROME=/path/to/chrome node scripts/check_pages.mjs`.

**Tennis.** The script downloads ATP match results, extracts every title and every Big Three head-to-head match, and **checks the result against the official totals** (Grand Slams, Masters 1000, ATP Finals, titles and head-to-head records). The build fails if any number is off.

Rules applied:

- Walkovers are excluded from head-to-head and win-loss records, as on the ATP site.
- Team events (ATP Cup, United Cup, Laver Cup, Davis Cup) don't count as titles; the Olympics do.
- Dates are the estimated day of each final (the source data only has the start of each tournament).

**Grand Slams.** The script reads every Grand Slam match since Roland Garros 1968 from the same ATP files. Any major the files don't cover yet is rebuilt match by match from its Wikipedia draw page (all 127 matches must parse, or the build fails). Nationality is the one represented at the time: a small [override file](data/manual/slam_nationality_overrides.csv) corrects players the ATP lists under today's country (Lendl and Kodeš for Czechoslovakia, for example). The build checks title totals for the all-time leaders and the number of editions of each major.

**Women's Grand Slams** use the same pipeline with the WTA match files and the women's draw pages. A [separate override file](data/manual/wta_nationality_overrides.csv) restores the nationality of the time where the WTA lists today's (Navratilova and Mandlíková for Czechoslovakia, Seles for Yugoslavia); for every player, Czech, Slovak, former Soviet and former Yugoslav codes before those countries existed become Czechoslovakia, the Soviet Union and Yugoslavia.

**Masters 1000 and WTA 1000.** Wikipedia's yearly results tables (one page per season since 1990) decide which finals count, which matters for the WTA, whose level codes in the match files don't mark its top tier consistently. Each final is matched to its tournament in the ATP or WTA match files by its two finalists, and every match of that tournament feeds the match records; events the files don't cover yet are rebuilt from their Wikipedia draw pages (a draw must have one match fewer than it has players). The builds check the title counts of the all-time leaders and the number of finals in each season; the ATP titles by country match Wikipedia's own table.

**WTA records** are counted like the ATP's, from tour-level finals in the WTA match files. The match data is incomplete for the 1970s and 80s, so the builds check recent careers exactly (Serena Williams's 73 titles) and early ones within a tolerance (Evert, Navratilova).

**NBA.** The script reads Wikipedia's [List of NBA champions](https://en.wikipedia.org/wiki/List_of_NBA_champions) table, maps every historical team name to its current franchise (the Minneapolis Lakers count for the Lakers, the Seattle SuperSonics for the Thunder) and checks that every season is present and that all titles through 2026 match the known totals. A new team name makes the build fail until it is added to [`data/nba/franchises.json`](data/nba/franchises.json).

**Football.** For the Libertadores and Champions League, the script reads each competition's list of finals, all-time club table, all-time top scorers and most-appearance table from Wikipedia, and maps clubs to crests through [`data/football/clubs.json`](data/football/clubs.json) (a club missing from that file still appears, with a lettered badge). It checks that there is one final per season and that every club's title count matches the known history. The world champions page combines the three competitions from Wikipedia's list of world champion clubs (checked against known title counts and the number of finals per competition). The Argentine national cups come from Spanish Wikipedia's list of national cups, checked club by club against its amateur and overall totals tables; their descriptions are kept in [`data/football/argentine_cups.json`](data/football/argentine_cups.json). The Argentine page reads the list of Primera División champions and must match, club by club, the title totals on the same page; amateur and professional titles and the rival associations come from the season labels (FAF, AAmF, LAF). Its all-time tables come from Spanish Wikipedia (based on RSSSF) and are shown as published.

**Coaches and players.** The Champions League, Copa Libertadores, Argentina, England, Italy, Spain, France and Brazil pages show the coaches with the most titles (and, for the two cups, the most finals) and every champion's coach, plus the players with the most titles where Wikipedia keeps a list (not for Spain or France; England's covers the Premier League era, Italy's the single-group Serie A and Argentina's the professional era). Coaches come from the lists of winning managers, the Libertadores finals table on Spanish Wikipedia (both coaches of every final) and, for the Champions League runners-up, each final's line-ups (saved in `data/raw/football/final_managers.json`). Every coach's title is matched to the champion of that season on the page's own dataset by year and club, so the counts line up with the page; the build fails if fewer than 95% of the titles get a coach, and checks known records (Ancelotti's 5 Champions League titles in 6 finals, Bianchi's 4 Libertadores, Ferguson's 13 English titles, Giggs's 13 Premier League medals, Buffon's 10 scudetti, Pelé's 6 Brazilian titles and others).

**Super Bowl.** Every Super Bowl comes from Wikipedia's list of Super Bowl champions (the winner's conference from the table's AFC/NFC shading), the NFL titles of 1920–1969 from the list of NFL champions, the MVPs from the Super Bowl MVP list and both head coaches of every game from the list of Super Bowl head coaches. Every historical team name maps to today's franchise through `data/nfl/franchises.json`. League titles follow the NFL's count: the NFL championship through the 1969 season, then the Super Bowl (AFL titles aren't included). The build checks every franchise's Super Bowl wins through Super Bowl LX, one league champion per season since 1920, the Packers' 13, Bears' 9 and Giants' 8 titles, Tom Brady's 5 MVPs and Bill Belichick's 6 wins in 9 Super Bowls.

**Stanley Cup.** Every Final since 1915 comes from Wikipedia's list of Stanley Cup champions (both coaches of every Final are in the same tables) and the Conn Smythe winners from the trophy's page; team names map to today's franchise through `data/nhl/franchises.json`, with the original Ottawa Senators (to 1934) kept apart from today's club. The champion's country is where it was based that year. The build checks every franchise's Cups against the same page's appearances tables, the Canadiens' 24, that only 1919 and 2005 have no champion, Patrick Roy's 3 Conn Smythes and Scotty Bowman's 9 Cups as coach.

**Winning coaches (team sports).** The World Cup, World Club Champions, NBA and every international team tournament page (rugby, basketball, volleyball, field hockey, handball, Olympic football) list the coaches with the most titles and every champion's coach. Lists of winning coaches are used where Wikipedia keeps one (World Cup, Intercontinental Cup, Club World Cup, FIBA World Cup, Rugby World Cup, NBA). Otherwise each edition is followed from the competition's editions table to its squads or rosters page, where the champion's section names its head coach (FIBA roster footers, coach tables, transcluded roster templates and team articles are read too); when no such page exists, the coach in office that year comes from the champion's national team article (or its German, French, Spanish or Italian version, with names mapped back to English Wikipedia). A year with a change of coach is left blank rather than guessed, and the page says how many titles have a known coach. Found coaches are saved in `data/raw/football/team_coaches.json`, so later runs only look up the editions still missing. Checks: Pozzo's 2 World Cups, Bianchi's 3 world club titles, Phil Jackson's 11 NBA titles, Krzyzewski's 2 World Cups and 3 Olympic golds, Jacobsen's 4 handball world titles, Bernardinho's 2 Olympic golds and others; a dataset with a coach for fewer than 40% of its titles isn't written.

**National leagues.** One config per league (in `build_leagues.py`) names the Wikipedia list of champions, the top scorer pages and, where one exists, the all-time table (from Italian, Spanish or English Wikipedia). Every club's title count must match the totals table on the same page; the only documented exception is Rouen's 1944–45 wartime title, which the French totals table counts and the season list doesn't. Renamed clubs keep their titles through the aliases in `clubs.json` (Ambrosiana-Inter for Inter, Atlético Aviación for Atlético Madrid, SpVgg Fürth for Greuther Fürth), and a club's label only matches a club of the same country, so Chile's Everton or Arsenal de Sarandí never borrow an English crest.

**World Cup.** The script combines six Wikipedia pages (editions, finals, records and statistics, top goalscorers, team and player appearances) and checks that every edition since 1930 is present, that title counts match history and that each edition has its final, podium, hosts and tournament totals.

**Ballon d'Or.** Winners, nationality and club come from Wikipedia's Ballon d'Or article; the youth academy is read from each winner's own article (the last youth club in the infobox, with youth sides such as "Sporting CP (youth)" credited to the parent club). The build checks the number of awards of the multiple winners and that every year is present.

**Formula 1.** Drivers' and constructors' champions and the all-time race wins come from Wikipedia's F1 lists. The build checks one champion per season, the title counts of the record holders and the constructors' title totals.

**ATP & WTA Finals.** Every Finals match comes from the ATP and WTA match files, found by the tournament's name in each era (the Masters until 1989, then the Tour Finals, Masters Cup and the WTA's sponsor and host-city names), with walkovers left out of win-loss records. Wikipedia's list of finals gives every champion, checked against the match files edition by edition, plus the runners-up of the 1972–1974 women's editions the match files don't cover; host cities come from the venues tables. The build checks the title counts of the leaders, Federer's 59–17 record and 17 appearances, one champion per edition and a host for every year.

**World No. 1.** Every spell at No. 1 comes from the table on Wikipedia's lists of ATP and WTA No. 1s, with the flag the player carried at the time. The build checks each player's weeks against the same page's totals table, the number of players who have been No. 1, the longest runs (Federer's 237 weeks, Graf's 186) and that the spells follow one another with no gaps. The 2020 ranking freeze is kept as its own spell and counts for nobody.

**Tennis age records.** Champions come from Wikipedia's lists of Grand Slam singles champions and the ATP and WTA Finals pages; each tournament's last day is read from its own Wikipedia page and dates of birth from Wikidata. Both are kept in `data/raw/tennis/` and only new ones are looked up. Ages at No. 1 come from the first and last dates in Wikipedia's No. 1 lists, which give birth dates too. The build checks each Slam's Open Era champions against the Grand Slams pages, the known record holders (Alcaraz and Hingis the youngest No. 1s, Djokovic and Serena Williams the oldest, Chang and Lottie Dod the youngest major champions, Gore the oldest) and the players with a career Grand Slam.

**ATP records.** Titles and match records are counted from the ATP match files (plus the Wikipedia-sourced Slams and the manual supplement); weeks at No. 1 and year-end No. 1s come from Wikipedia. The build checks Federer's 103 titles and 1,251–275 record, Nadal's 92 titles and the weeks at No. 1 of the leaders.

**Olympic Games.** The medal table of every Games comes from the `{{Medals table}}` template on its Wikipedia page; the all-time table, the host cities and the athletes with the most medals and golds come from their own lists. Nation names and flags come from Wikipedia's comparison of IOC, FIFA and ISO codes. The build checks the leading nations at recent Games (the United States' 40-44-42 in Paris), the number of Games and the career medals of Phelps, Latynina, Bjørgen and Nurmi. The all-time table leaves out the 1912–1948 art competitions that the per-Games tables include, so the build reports, without failing, the few nations whose totals differ.

**Olympic tennis and boxing** share the swimming parser ([`olympic_events.py`](scripts/olympic_events.py)): boxing reads Wikipedia's list of medalists, one table per weight class; tennis reads the events table on each Games' tennis page, keeping doubles pairs together (a pair from two nations counts as a mixed team). The builds check the career medals of the leading players and boxers, the number of tennis events at each Games, that every boxing class since 1952 has two bronzes and the boxing gold counts of the United States and Cuba. Olympic football goes through the team tournament pipeline, which now reads age-group flags ({{fbu|23|BRA}}) and older FIFA codes (CSK, DDR).

**Chess.** World Championships, women's, rapid and blitz titles, the number ones, peak ratings, the Olympiad, the Candidates, the World Cup and the youngest grandmasters come from Wikipedia. Head-to-head records count the games in [PGN Mentor](https://www.pgnmentor.com/files.html)'s files for 40 players (kept in `data/raw/chess/pgn`). PGN files don't record the time control, so each game is classed as rapid or blitz by its event name, its time control when the name gives one, its place in a knockout round (tiebreaks) and online sites (rapid unless marked blitz); Chess960, blindfold, simultaneous, advanced and computer games are left out. The build checks the rapid and blitz title counts against the records tables, months at number one against Wikipedia's totals (Kasparov's 1994 months, when FIDE left him off its lists, are the one documented gap), the title counts of the leading champions and the Karpov–Kasparov classical record.

**Olympic swimming.** Wikipedia's lists of Olympic medalists in swimming have one table per event; the script reads every medalist, nation and time, splits ties (two swimmers sharing a medal) and keeps every named relay swimmer. The build checks the number of pool events at each Games since 1968 (35 in 2020 and 2024) and the career medals of the most decorated swimmers. The pages' own medal tables, kept by hand, don't always match their event lists, so they are only compared as a warning.

**Team tournaments.** One config per competition (in `build_tournaments.py`) names the Wikipedia page and table for its editions and, where they exist, its participation table, all-time table and player records. The parser reads flag templates of every sport, so champion, runner-up, third and fourth come out as country codes; each build checks the title counts of the most successful nations.
